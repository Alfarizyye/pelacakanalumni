# 📊 Sistem Pelacakan Alumni UMM (UMM Tracker)

## 📝 Deskripsi
Sistem ini merupakan aplikasi berbasis web untuk melakukan pelacakan alumni Universitas Muhammadiyah Malang (UMM).  
Aplikasi ini membantu dalam mengidentifikasi status alumni berdasarkan hasil pelacakan data dari berbagai sumber dengan pendekatan **coverage, accuracy, dan confidence score**.

---

## 🚀 Fitur Utama

### 🔹 Dashboard
- Menampilkan ringkasan:
  - Total Data Alumni
  - Alumni Teridentifikasi
  - Alumni Belum Dilacak

### 🔹 Penilaian Sistem
- **Coverage Assessment**  
  Mengukur persentase kelengkapan data alumni dari parameter yang tersedia

- **Accuracy Assessment**  
  Mengukur tingkat keakuratan data hasil pelacakan

- **Confidence Score**  
  Menentukan tingkat kepercayaan terhadap hasil identifikasi alumni

---

### 🔹 Query Generator
- Menghasilkan query pencarian otomatis berdasarkan data alumni
- Membantu proses pelacakan alumni

---

### 🔹 Tracking Sources
- Menampilkan status hasil pelacakan data
- Memberikan informasi apakah data berhasil ditemukan atau diperbarui

---

### 🔹 Data Alumni
- Menyimpan dan menampilkan data alumni
- Digunakan sebagai sumber utama pelacakan

---

### 🔹 History Pelacakan
- Menyimpan riwayat proses tracking alumni
- Memudahkan monitoring dan evaluasi
